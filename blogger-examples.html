Reveal something after payment

Listen for bkash:success to show a thank-you note or a download link.

Preview
<script src="https://YOUR-GITHUB-NAME.github.io/bkash-blogger-payment/blogger.js"></script>

<button data-bkash-amount="250" data-bkash-product="Members Guide">Unlock the guide for ৳250</button>

<div id="paid-content" hidden>
  <h3>Thanks for your purchase!</h3>
  <p>Your transaction ID is <b id="paid-trx"></b>. We will email the guide within an hour.</p>
</div>

<script>
  document.addEventListener('bkash:success', function (event) {
    if (event.detail.product === 'Members Guide') {
      document.getElementById('paid-trx').textContent = event.detail.trxID;
      document.getElementById('paid-content').hidden = false;
    }
  });
</script>

Hidden content is still in the page source. For files worth protecting, send them by email after you've confirmed the transaction ID in your merchant portal or with /verify.

Blogger tips

Small things that save time.

  • Paste in HTML view and publish from there.Switching back to Compose view can reformat custom HTML.
  • Selling in many posts? Put the script in your theme once.Then each post only needs the <button> line. See the setup guide.
  • Using PRICES on the Worker? Keep product names identical.data-bkash-product="Premium eBook" must match the key "Premium eBook" exactly.
  • Home page shows several posts? That's fine.Buttons need no unique IDs, and the script only loads once.
